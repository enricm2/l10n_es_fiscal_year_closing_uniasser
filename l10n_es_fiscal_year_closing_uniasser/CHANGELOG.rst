Changelog

18.0.1.0 (2024-12-XX)
=====================

**Features**

* Implementación completa del cierre de ejercicio fiscal español
* Asiento de regularización automático (grupos 6 y 7 → cuenta 129)
* Asiento de cierre de balance (grupos 1-5)
* Asiento de apertura del nuevo ejercicio
* Creación automática de diarios REGUL, CIERRE y APERT
* Proceso reversible con cancelación segura
* Integración con sistema de mensajería (chatter)
* Soporte multi-compañía
* Validación automática de asientos generados
* Interfaz intuitiva con estados de workflow

**Traducciones**

* Español (es)
* English (en_US)
* Français (fr)
* Português (pt, pt_BR)
* Deutsch (de)
* Italiano (it)
* Nederlands (nl)
* Polski (pl)
* Русский (ru)
* Türkçe (tr)
* Català (ca)
* Galego (gl)
* Euskara (eu)
* Y más idiomas disponibles

**Mejoras Técnicas**

* Consultas SQL optimizadas para alto rendimiento
* Manejo robusto de errores y validaciones
* Logging completo para auditoría
* Código documentado según estándares OCA
* Compatibilidad completa con Odoo 18.0

**Seguridad**

* Grupos de acceso configurados
* Validaciones de permisos
* Protección contra eliminación accidental
* Confirmación requerida para cancelación
