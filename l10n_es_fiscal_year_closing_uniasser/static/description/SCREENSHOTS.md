# Screenshots Guide

Para completar la publicación en la tienda de Odoo, necesitas añadir las siguientes capturas de pantalla:

## Imágenes Requeridas

### 1. banner.png (1200x600 px)
Banner principal del módulo mostrando el logo y título del módulo con un diseño atractivo.

### 2. screenshot_01.png (1024x768 px recomendado)
**Vista de Lista de Cierres**
- Captura de la vista de lista mostrando varios cierres de ejercicio
- Debe mostrar: nombre, fechas, estado, asientos generados
- Título sugerido: "Gestión de Cierres de Ejercicio"

### 3. screenshot_02.png (1024x768 px recomendado)
**Formulario de Configuración de Cierre**
- Captura del formulario de cierre en estado 'draft'
- Debe mostrar: campos de fechas, diarios, opciones
- Título sugerido: "Configuración del Cierre Fiscal"

### 4. screenshot_03.png (1024x768 px recomendado)
**Vista de Asientos Generados**
- Captura mostrando los asientos de regularización, cierre y apertura
- Debe mostrar: enlaces a los asientos, estado 'done'
- Título sugerido: "Asientos Contables Generados"

### 5. screenshot_04.png (opcional)
**Vista de Asiento de Regularización**
- Captura de un asiento de regularización validado
- Mostrando las líneas contables con cuentas de grupos 6 y 7

### 6. screenshot_05.png (opcional)
**Vista de Asiento de Cierre**
- Captura de un asiento de cierre validado
- Mostrando las líneas contables del balance

## Cómo Crear las Capturas

1. Instala el módulo en una instancia de Odoo 18
2. Crea un cierre de ejercicio de ejemplo con datos reales
3. Ejecuta el proceso completo
4. Toma capturas de pantalla en alta resolución
5. Edita las imágenes para:
   - Ocultar datos sensibles si es necesario
   - Añadir anotaciones o flechas explicativas (opcional)
   - Optimizar el tamaño del archivo (PNG comprimido)

## Ubicación

Guarda todas las imágenes en:
```
/opt/odoo18/custom-addons/l10n_es_fiscal_year_closing/static/description/
```

## Notas

- El archivo `icon.png` (128x128 px) ya existe
- Usa resoluciones altas pero optimiza el tamaño de archivo
- Asegúrate de que las capturas muestren una interfaz limpia y profesional
- Evita mostrar datos de clientes reales o información confidencial
